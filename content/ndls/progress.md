An honest running log of where the project actually is. Newest first.

{{< milestone date="June 2023" status="done" >}}
**Developing interest in Neurodevelopmental Conditions.** Late diagnosed of attention deficit/hyperactivity disorder (ADHD) after a year of depression and anxiety treatment and therapy with psychiatrist and psychotherapist. Starting read 'books' 
{{< /milestone >}}

{{< milestone date="September 2026" status="done" >}}
**Framework proposal posted.** The full NDLS framework — the causal layer, the
agent-based layer and the capabilities layer — written up and deposited on
figshare under its own DOI, so it can be cited and argued with while the work
is still being built.
{{< /milestone >}}

{{< milestone date="Now" status="now" >}}
**Mapping the data landscape.** Working out which linked longitudinal cohorts
can actually carry the causal layer: what is measured, how often, for whom,
and where the gaps in neurodevelopmental coverage are.
{{< /milestone >}}

{{< milestone date="Next" status="next" >}}
**A first simulation skeleton.** A minimal agent-based model — one cohort, one
setting, one capability — to find out which parts of the framework survive
contact with code before the full version is attempted.
{{< /milestone >}}

{{< milestone date="Later" status="next" >}}
**Capability measurement.** Deciding how capability is to be operationalised
from the variables real datasets hold, which is where the normative layer
either earns its place or does not.
{{< /milestone >}}
